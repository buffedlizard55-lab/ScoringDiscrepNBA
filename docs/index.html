Start here: what is this?

This project began with a single incident report: one source showed a 213-point final total for an NBA game while another showed 214. That report is tracked below as UNVERIFIED — its game has not been identified yet, so it is treated as an open investigation, not a fact. Everything else on this page is a researched case with cited evidence.

⚠ The 213-vs-214 report is UNVERIFIED. Game, date, teams, and competing sources are unknown. See the record “UNVERIFIED: Originating report” in the case list for the investigation checklist. One-point total corrections like this have verifiably happened twice in our collection (Oct 2024: 243→244, Nov 2025: 262→263) — both were missed free-throw entries corrected the next day.
How to read a case. Each record answers one question first: was the NBA's own official record wrong, or only a secondary source? Then it shows the original value → correction → final official value, the timeline, the cause (confirmed / suspected / unknown), and the sources with direct links so you can re-verify each claim yourself.

      Live monitor feed

      Every game window, an automated job compares the ESPN scoreboard feed against NBA liveData box scores and play-by-play (cross-source totals, quarter sums, and PBP running-score consistency). Disagreements open an investigation record here; nothing becomes a case without human verification.

      Methodology: no hallucinations

      Verification rules

      1. Every factual claim traces to a cited source with a direct link.
      2. Unknown means null. Missing dates, scores, clocks, and causes are left blank with an open question — never guessed.
      3. Official vs secondary first. Each record rules on whether the NBA's own record was wrong.
      4. Disagreements are preserved, not papered over (see “Disputed points” in each record).
      5. “Verified” is earned: ≥2 sources incl. a strong tier, zero open questions. Everything else stays partial, disputed, or unverified.
      6. Corrections are appended, never overwritten — original, correction, and final are all kept.

        Limitations & roadmap

        Known limitations.
        • The collection is a sample, not a census — shares are not league-wide rates.
        • Primary NBA statements are still missing for several cases (see each record's open questions).
        • Pre-2000s coverage is thin (one 1982 case); the Nets–76ers upheld protest (3rd of 3 since 1952 per USA Today) is a known gap.
        • The monitor cannot see arena scoreboards or TV bugs — display-only errors need human spotters.
        • Live feeds lag each other by seconds; transient mismatches are expected noise, not findings.
        Next up.
        • Identify the originating 213-vs-214 game (or reclassify as unrecoverable with a decision log).
        • Locate primary NBA rulings for the 2019, 2014, 2008, 1982 protests.
        • Add the Nets–76ers upheld protest and expand pre-2000s research.
        • Add box-score archive snapshots (pre/post correction) as evidence attachments.
        • Backfill monitor: nightly re-check of the previous 7 days to catch next-day corrections.
