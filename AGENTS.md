# Project starting point

At the start of every session, read `README.md`, including the founding brief,
then `docs/REPOSITORY_REVIEW.md`, `ALERTING.md`, and the latest review-pass log.
Use Maximize P(Win) and Own the Outcome to prioritize trustworthy outcomes over
feature counts. Never describe schema validation as factual verification.

- Preserve original evidence. Unknowns remain null or explicitly unverified.
- A feed mismatch is a candidate, not proof that the NBA record was wrong.
- Never infer league-wide incidence from this selected historical collection.
- Document inaccessible sources and tests actually run, not assumed results.
- Run the offline tests and both historical and active validators before PRs.
- Research must cite direct sources and distinguish evidence from derivation.
